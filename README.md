# 🐍 Snake Water Gun Game

An interactive Python-based implementation of the classic Snake Water Gun game.

## 🚀 Project Overview

This project simulates the popular Snake Water Gun game where a user competes against the computer. The computer generates random moves while the program determines the winner based on predefined game rules.

Built as part of my Python learning journey to strengthen concepts such as:
- Conditional Statements
- Loops
- User Input Handling
- Random Module
- Basic Game Logic

## ✨ Features

✔ Interactive Command Line Gameplay  
✔ Random Computer Moves  
✔ Instant Winner Calculation  
✔ Beginner-Friendly Code Structure  
✔ Lightweight and Fast Execution  

## 🛠 Technologies Used

- Python 3
- Random Module

## 🎮 Game Rules

| Choice | Defeats |
|---------|----------|
| Snake 🐍 | Water 💧 |
| Water 💧 | Gun 🔫 |
| Gun 🔫 | Snake 🐍 |

## 📂 How to Run

1. Clone the repository
2. Open the project folder
3. Run:

```bash
python main.py
```
